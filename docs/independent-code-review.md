2026-10-05: راجع وكيل مستقل كامل الشفرة الجديدة بمهارات ponytail وclean-code-guard وcode-review، قياسًا إلى HEAD `281089c9020160bdeb9c557e0e2ef2cb4eebf4eb`، بما يشمل الملفات غير المتتبعة. شملت القراءة 70 ملف شفرة وضبط وفحص؛ وصُنّف ملفا دليل تاريخي خارج الشفرة مع مراجعة أصلهما وبنيتهما. لم تشمل القراءة أجسام المكتبات الخارجية المصغرة، واقتصرت على جردها ورخصها وموضع DOMPurify المتصل بالعيب.

## Standards

عيب واحد P2: تحليل رابط Markdown مشوّه قد يقطع العرض وحفظ الرد. أُحيط تحليل URL بمعالجة TypeError وحده، ويُنزع href مع إبقاء النص.

## Spec

خمسة عيوب، أُصلحت في مواضعها دون اعتماد جديد أو إعادة هيكلة أخرى:

- P1: فشل تثبيت Service Worker بسبب /index.html غير المقدّم؛ حُذف من precache وبقي /.
- P1: آخر سطر NDJSON مبتور قد يمنع إقلاع الخادم؛ تُحفظ النسخة الأصلية في ملف خاص فريد، ويُستعاد المقطع السليم قبل الاستبدال الذري. السطر المكتمل الفاسد يظل خطأً صريحًا، ولا يُعاد الدور المنقطع.
- P2: خيار MCP sse معلن بلا عقد CLI صالح؛ حُذف من النموذج، وبقي stdio/http.
- P2: --version قد يوقّع حزمة تخالف server/version.json؛ يُرفض الاختلاف قبل التحضير أو إنشاء الناتج.
- P2: effort المحفوظ لا يصل إلى الجلسة الجديدة أو الاستئناف؛ أُضيف في الموضعين مع بقاء اختيار المستخدم الصريح مقدّمًا.
