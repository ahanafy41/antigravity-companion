# عقود استرداد الوظائف

2026-10-07. بحث وتخطيط فقط؛ لا تغيير في شفرة الإنتاج أو حساب أو هاتف. أدلة الوثائق قرئت مباشرة من موقع agy، وأدلة النسخة المحلية اقتصرت على HELP. الدليل على Windows لا يثبت توافق نسخة Termux أو قبول الهاتف.

## معيار الإثبات

«مثبت» يعني نصًا رسميًا أو فعلًا معلنًا في HELP المحلي. «مرشح» يعني وصلة هندسية لم تختبر. غياب الأمر من قائمة HELP لا يثبت استحالة الوظيفة؛ قد يملكها ملف إعداد رسمي أو أمر print مستقل أو واجهة تفاعلية. ولا يدل نجاح إضافة إعداد على اتصال فعلي أو مصادقة.

المساعدة المقروءة: `agy --help`، `agy update --help`، `agy mcp --help`، `agy mcp list --help`، `agy mcp add --help`، `agy plugin --help`. لم تنفذ أوامر login أو status أو update أو enable أو OAuth، ولم تقرأ أسرار الحساب. ضبط `AGY_NO_UPDATE_CHECK=1` وحذف `AGY_AUTO_UPDATE` في عملية البحث؛ وبعد مراجعة الوثائق أضيف `AGY_CLI_DISABLE_AUTO_UPDATE=true` إلى آخر جولتي MCP HELP. الوثائق تثبت المتغير الأخير وحده لمنع الترقية التلقائية؛ لا نزعم أن الأول يكافئه. [مرجع منع auto-update](https://www.agy.dev/docs/cli/troubleshooting/#resolve-self-updater-locks-and-failures).

## بوابات القبول

للجدولة دليل إضافي: وثيقة Hooks المشتركة، التي تذكر CLI صراحة، تجرد أداة `schedule` بوسائط `DurationSeconds` و`CronExpression` و`MaxIterations` و`Prompt`، وأداة `manage_task`. هذا يثبت اسم الأداة ووسائطها المعلنة، ولا يثبت منفذ CRUD حتميًا تستدعيه Companion مباشرة، ولا وجودها في نسخة Termux الحالية. فحص `init.tools` في تجربة لاحقة مأذونة قد يثبت الإتاحة؛ إصدار أمر لغوي للموديل لا يكافئ حفظ جدول حتمي. [الأدوات الرسمية](https://www.agy.dev/docs/hooks/#system-and-execution).

أولًا: يراجع المستخدم خطة الاسترداد؛ البحث لا يجيز تنفيذها. ثانيًا: يثبت adapter المصغر على الإصدار المستهدف، وبأقل فعل مأذون؛ يبدأ quotas بقراءة print، والترقية تظل فعلًا مؤثرًا مستقلاً. ثالثًا: يفحص الأداء الأصلي كاملًا، لا مجرد ظهور الزر: مالك البيانات، ومصادقة فعلية، وخيارات الجلسة، والإلغاء، والانقطاع، والحفظ، ولوحة المفاتيح وأسماء قارئ الشاشة. لا تختزل مطلبًا أصليًا إلى رسالة «غير متاح» أو مسار تفاعلي ناقص وتعده مستردًا.

الفجوات الباقية معلومة: نسخة Termux لم تفحص؛ هيئة نص `/usage` لم تستخرج؛ مصادقة MCP عبر headless غير مثبتة؛ تبديل مهارة منفردة غير مثبت؛ الجدولة مع التشغيل الخلفي للهاتف تحتاج قبولًا خاصًا. واجهة provider مستقلة زيادة تحتاج طلبًا منفصلًا، وليست فقدًا مثبتًا من main. أما وجود عقود quota print وupdate وملف policy وGemini provider فهو مثبت في المصادر أعلاه.
