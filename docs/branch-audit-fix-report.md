| العيب | الإصلاح والدليل |
|---|---|
| ترقية APK دون توافق الخادم | كل فتح للمثبّت يسبقه فحص APK وشهادته ونسخته المضمّنة، ثم health جديد مع HMAC ومطابقة version وdevice_protocol=journal_ready_epoch_v1. الخادم غير المتوافق يمنع فتح المثبّت ويطلب تثبيت الخادم الموقع وإعادة تشغيله يدويًا. لا تفعيل تلقائي لحزمة ولا ثقة في serverConnected المخزونة. |

| غياب أوامر CLI من الاقتراحات | commands أصبحت قدرة معلنة ومتاحة عند وجود CLI؛ فحص HTTP يقابلها بمسار الفهرس. |
| اختيار النموذج يسقط الوكيل | اعتماد النموذج يحفظ بقية sessionOptions؛ Chromium يثبت agent في طلب إنشاء الجلسة واستئنافها. |
| انقطاع كتابة الجلسات والأدوار | سجل معاملة مؤقت يسبق كتابة الملفين؛ يعاد تطبيقه عند الإقلاع قبل قراءة الحالة. تبقى صيغة الملفين والحقول المجهولة، وتزال المعاملة ونسختها بعد الإتمام. الدور المفقود من حال قديمة يعرض interrupted مع سبب صريح، دون اختلاق نص أو إعادة CLI. |
| إلغاء Windows لا ينهي الأبناء | taskkill /PID /T /F مقصور على العملية المملوكة قبل إنهاء الأب. كل خروج غير صفري أو انتهاء مهلة يعلن تعذر تأكيد الإلغاء؛ لا نجاح مستنتج من انتهاء الأب. فحص فعلي أثبت انتهاء الابن وبقاء عملية شاهد مستقلة. |

مرجع أمر Windows: [Microsoft taskkill](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/taskkill).

## ما كشفه استكمال التدقيق

- إعادة فتح لوحات النموذج والوكيل والمجلد كانت تستعيد settings بدل الاختيار الجاري؛ صارت تقدم sessionOptions، مع فحص Chromium رجوعي.
- إخفاق حفظ بدء الدور في الخادم العامل كان يترك running بلا task؛ صار interrupted، وإعادة معرف الطلب نفسه تستعيد النتيجة دون تشغيل CLI. فحص HTTP/SSE يثبت غياب task/process.
- إخفاق حفظ خاتمة الدور لا يعلن completed متينًا؛ يحفظ النص المتاح في الذاكرة ويعلن interrupted وسبب الحاجة إلى الاستعادة. وحفظ الخاتمة يسبق بث حدث الخطأ، كيلا يسقط الحفظ بإخفاق NDJSON.
- أزيلت نسخة المعاملة المؤقتة القديمة بعد الإتمام، وأصبح إخفاق taskkill صريحًا ولو انتهى الأب أثناءه. كلا المسلكين فُحص قبل الإصلاح وبعده.

راجع وكيل الويب Backend قراءةً مستقلة، وراجع وكيل Android الإصلاحات الأخيرة. أغلقت المراجعة المحددة المآخذ المؤكدة، ولم تجد عيبًا جديدًا في فروق الإصلاح الختامية. clean-code-guard وtest-guard: سليمان في النطاق المراجع؛ docs-guard قابل الحصيلة بالشفرة وأدلة الفحص. لا دعوى بخلو كامل التطبيق من كل عيب ممكن.
