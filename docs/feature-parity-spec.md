# معيار التكافؤ مع main

2026-10-07 — `docs: define main feature parity`؛ بحث مكتمل، تنفيذ الاسترداد لم يبدأ وينتظر اعتماد الخطة.

## المقصد والدليل

حفظ وظائف الأصل الفعلية في إعادة الهيكلة، مع إصلاح عيوبها؛ لا يكفي نقل أسماء اللوحات أو إظهار سبب التعذر. الأصل commit `281089c9020160bdeb9c557e0e2ef2cb4eebf4eb`؛ ملفات الفرع الحالية غير المودعة هي محل المقابلة. [حصر الأصل](main-feature-baseline.md) يثبت أفعال الشفرة بأسطر Git، و[عقود الاسترداد](feature-restoration-contracts.md) يفصل HELP المحلي والمراجع الرسمية عن المسالك التي لم تختبر. هذه أدلة ساكنة وعقود معلنة، وليست قبولًا ميدانيًا.

تُصحّح الأحكام السابقة: أمر `agy update` معلن في النسخة المحلية؛ و`agy -p /usage` موثق خارج stream-json؛ ولـCLI ملف أذون رسمي. لم يثبت في main محرك مستقل أو backend لمزودين آخرين. الجدولة الأصلية سجل ناقص لأحداث أدوات CLI، لا مجدول دائم ثبت نجاحه. فلا يعد إنشاء محرك مستقل جزءًا من استرداد main، ولا تُسوّى نواقص الأصل بصحة التنفيذ.

تبقى هذه الصفوف `not_started` حتى اعتماد الخطة. لا تعني صعوبة العقد إسقاط المقصد؛ تُسجّل الفجوة، ويُعرض قرار ضيق بعد تجربة العقد بدل صنع زر يوهم اكتمال الوظيفة. يستكمل حصر مسارات الأصل في المرحلة صفر؛ أي وظيفة إضافية ثابتة تدخل الجدول قبل إقفال التكافؤ. الأفعال الصوتية ليست محرك provider مستقلًا؛ لها مسلك خلفي وجسر جهاز في الأصل.

## الحدود ومعيار الإقفال

تصان الملفات والإعدادات والحقول المجهولة والاعتمادات وشهادة التوقيع؛ لا نقل للأسرار إلى API أو logs أو argv. تبقى حراسة الاقتران وCSRF وHMAC وملكية العمليات وسجل الطلبات. لا رجوع إلى CORS المفتوح أو shell حر أو `--dangerously-skip-permissions`، ولا تكرار تلقائي لفعل مجهول.

يُقبل كل صف بدليل وظيفة كاملة: فعل ونتيجة وإخفاق وإلغاء حيث ينطبق، وحفظ بعد restart، ومصدر حال واضح، وأسماء قارئ الشاشة وترتيب Tab ورسائل مفهومة دون الاعتماد على اللون. فحوص fixtures لا تثبت حسابًا حيًا أو Termux أو الهاتف. تصدر الحصيلة النهائية ثلاث حالات منفصلة: التنفيذ المحلي، وقبول التكامل الحقيقي، وقبول الهاتف؛ لا دعوى تكافؤ كامل مع بقاء صف مطلوب ناقصًا.

مرجع التنفيذ المقترح: [خطة الاسترداد](feature-restoration-plan.md).
