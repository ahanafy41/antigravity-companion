## 🎯 ملخص المشاكل والأهداف

1. **الذاكرة الداخلية وكارت الميموري (External SD Cards)**:
   - الضغط على "📱 الذاكرة" لا يفتح مسار `/storage/emulated/0` بسبب رفض `workspaces(request)` للمسار خارج مجلد Termux الافتراضي.
   - كارت الميموري الخارجي (SD Card مثل `/storage/9C33-6BBD`) غير موجود ولا يمكن الوصول له.
   - **الهدف**: السماح ديناميكياً بمسارات الذاكرة الداخلية وكروت الميموري المكتشفة في `/proc/mounts` واكتشافها وعرض أزرار تنقل سريع لها تلقائياً.

2. **الملفات المخفية (Hidden Files)**:
   - لا يوجد زر أو إمكانية لإظهار أو إخفاء الملفات والمجلدات المخفية (التي تبدأ بـ `.`).
   - **الهدف**: إضافة زر تبديل سلس وواضح `👁️ إظهار/إخفاء المخفي` مع حفظ التفضيل وتصنيف واضح لقارئ الشاشة.

3. **زر "تعيين كمشروع نشط" (Set Active Project)**:
   - الزر يفشل أو لا يثبت المسار في إعدادات مساحات العمل الموثوقة `trustedWorkspaces`.
   - **الهدف**: تحديث `cwd` و `trustedWorkspaces` بالتزامن، وتحديث حالة الواجهة وعرض اسم المشروع النشط بوضوح.

4. **زر "إرسال الملف للوكيل" (Send File to Agent)**:
   - الزر كان محصوراً داخل عارض الملفات النصية فقط، وعندما يكون الملف ثنائياً أو أكبر من 1 ميجابايت يفشل فتح العارض تماماً ولا يمكن إرسال الملف.
   - **الهدف**: توفير زر "إرسال للوكيل" مباشر بجانب كل ملف في القائمة، بالإضافة لدعم معاينة الملفات بجميع أنواعها وأحجامها.

## 🗺️ خريطة الملفات المتأثرة

| الملف | المسؤولية والدور في التعديل |
| :--- | :--- |
| `server/application.py` | دعم مسارات التخزين الداخلية والخارجية في `workspaces(request)` واكتشاف كروت الميموري، وإرجاع قائمة `storages` في `/api/v1/files`. |
| `server/web/main-v1-adapter.js` | معالجة `fs/select` لتحديث `cwd` و `trustedWorkspaces`، وتمرير قائمة `storages`. |
| `server/web/main-ui.js` | إعادة هيكلة شريط التنقل لعرض كروت الذاكرة ديناميكياً، زر الملفات المخفية، فرز المجلدات أولاً، وأزرار إرسال الملف للوكيل. |
| `server/web/main-ui.css` | تحسين مظهر شريط التنقل وأزرار الملفات وإتاحتها لقارئ الشاشة. |
| `server/web/index.html` | إبراز اسم المجلد/المشروع النشط في الواجهة. |
| `scripts/run_backend_tests.py` | اختبارات التحقق لضمان عمل مسارات التخزين وحماية المسارات الخاصة. |
