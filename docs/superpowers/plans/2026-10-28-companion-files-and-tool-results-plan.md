# خطة تنفيذ: إصلاح مستعرض الملفات وتطوير عرض نتائج الأدوات والبحث والروابط

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

---

## 🎯 ملخص الهدف والمشكلتان المرصودتان

1. **المشكلة الأولى (زرار وملفات ومجلدات المشروع 📁⚙️)**:
   - مستعرض الملفات لا يعرض كل الملفات أو يفشل في مجلدات معينة بسبب قيود المسارات وصلاحيات `workspaces` وضيق الحجم.
   - زري "تعيين كمشروع نشط" و "مشروع جديد" بهما مشكلات في التزامن وتطبيق المسار الفعلي داخل السيرفر وتحديث الإعدادات (خاصة تحديث `cwd` و `trustedWorkspaces`).
   - غياب التنظيم، الفرز (مجلدات أولاً ثم ملفات)، والتمييز البصري والصوتي الواضح لقارئ الشاشة TalkBack / Jieshuo.

2. **المشكلة الثانية (التعامل مع الأدوات ونتائجها 🛠️📄🔍)**:
   - نتائج الأدوات (Tool Outputs) تظهر بنصوص خام أو تفتقر إلى الصياغة البشرية المفهومة.
   - أداة البحث في الويب (`search_web`) وقراءة الروابط (`read_url_content` / `fetch` / `browser_read`) ومخرجات قراءة الملفات (`read_file`): المخرجات غير واضحة والروابط لا تظهر بشكل منظم.
   - الحاجة إلى دمج بطاقات نتائج الأدوات بشكل إنساني منظم، مع إظهار الروابط القابلة للنقر ونسخ المسارات، وعرض النتائج بتلخيص إنساني ذكي وواضح لقارئ الشاشة.

## 🗺️ خريطة الملفات المتأثرة

| الملف | المسؤولية والدور في التعديل |
| :--- | :--- |
| `server/application.py` | إصلاح مسارات الملفات `api_path`، دعم تصفح مجلدات النظام المسموحة، وضمان استجابة سريعة لقوائم الملفات. |
| `server/web/main-v1-adapter.js` | تحديث مهايئ الـ API لمعالجة `fs/select` و `fs/mkdir` مع حفظ `cwd` الفعلي في الإعدادات بشكل صحيح، وتمرير نتائج الأدوات والروابط. |
| `server/web/main-ui.js` | تطوير كامل لواجهة مستعرض الملفات (فرز ذكي، بحث، تمييز المجلدات، أزرار واضحة)، وتطوير عارض نتائج الأدوات بصياغة إنسانية وبطاقات مخرجات للبحث والملفات والروابط. |
| `server/web/main-ui.css` | تحسين مظهر مستعرض الملفات وقائمة الأدوات والبطاقات وإتاحتها الكاملة للمكفوفين. |
| `server/web/index.html` | تحديث هيكل حوار الملفات ومكونات المخرجات لدعم معايير ARIA. |

## 📋 المهام التنفيذية (Task Decomposition)

### Task 1: إصلاح وتطوير الواجهة الخلفية ومهايئ الملفات ومجلدات العمل
- [ ] فحص وتعديل دالة `api_path` و `workspaces` في `server/application.py` للسماح بتصفح المجلدات دون الوقوع في أخطاء المنع غير المبررة.
- [ ] تصحيح معالجة `fs/select` في `server/web/main-v1-adapter.js` لتحديث `cwd` وتعيين جلسة العمل فورياً وبدون فقدان الاتصال.
- [ ] تصحيح دالة `fs/mkdir` وإرجاع المسار المنشأ بدقة.

### Task 2: إعادة تصميم وهيكلة مستعرض الملفات في الواجهة (UI/UX)
- [ ] تنظيم عرض الملفات في `server/web/main-ui.js`:
  - المجلدات أولاً بأيقونات وأوصاف واضحة، تليها الملفات مرتبة أبجدياً.
  - إضافة شريط بحث وتصفية سريع للملفات في المجلد الحالي.
  - إظهار مسار المجلد الحالي كشريط مسار تفاعلي (Breadcrumbs) للتنقل السريع.
- [ ] تحسين زر "تعيين كمشروع نشط":
  - تنفيذ فوري مع تأكيد صوتي واضح عبر `announce`.
  - تحديث الشاشة الرئيسية وحقل الإدخال ليعكس اسم المجلد النشط مباشرة.
- [ ] تحسين زر "مشروع جديد":
  - إنشاء المجلد وتعيينه كمشروع نشط بخطوة واحدة سلسة.

### Task 3: تطوير صياغة وعرض نتائج الأدوات بأسلوب إنساني منظم
- [ ] تحديث دالة `getToolLabel` وتقديم دوال جديدة لتنسيق مخرجات الأدوات:
  - صياغة النتائج بلغة بشرية عربية طبيعية وودودة.
  - لأدوات البحث في الويب (`search_web`): استخراج النتائج وعرض العناوين والروابط بشكل منسق وقابل للنقر والنسخ.
  - لأدوات قراءة الروابط (`read_url_content` / `fetch`): إبراز رابط الصفحة وملخص محتواها بدقة.
  - لأدوات قراءة وتعديل الملفات (`read_file` / `write_file` / `edit_file`): توضيح اسم الملف، مساره، وحجمه مع زر نسخ للمسار ومعاينة منسقة.

### Task 4: الاختبار والتحقق الشامل (TDD & Verification)
- [ ] تشغيل اختبارات الواجهة الحالية والتأكد من نجاحها بالكامل.
- [ ] اختبار التصفح، إنشاء المجلدات، وتعيين المشروع النشط.
- [ ] اختبار محاكاة نتائج الأدوات والبحث والروابط والتأكد من توافقيتها مع قارئات الشاشة (TalkBack / Jieshuo).
