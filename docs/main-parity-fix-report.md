## ما لم يُدَّع استرداده

MCP OAuth/test، وتمكين مهارة منفردة، وحصص الحساب، وتحديث CLI العام: لا عقد CLI موثوق لهذه الأفعال في هذا التنفيذ؛ تبين الواجهة التعذر ومسار Termux. لم يُسترد PTY عام أو استخراج أسرار الحساب. إذن لا دعوى بتكافؤ كامل مع كل الأفعال القديمة المتجاوزة للعقود.

المراجع الأولية للأفعال المدعومة: [plugins CLI](https://www.agy.dev/docs/plugins?tab=cli)، [CLI reference](https://www.agy.dev/docs/cli/reference/)، [CLI features](https://www.agy.dev/docs/cli/features).

## حدود القبول والدمج

المراجع المستقل أغلق عيب args الأخير ولم يجد عيبًا مؤكدًا باقيًا في نطاق مراجعته. أمثلة Python وJava وJS كُتبت ولم تُنفذ. مراجعة الوصول ساكنة: أسماء الأزرار والتركيز والحال المكتوبة؛ قبول قارئ الشاشة والهاتف والترقية لم يثبت للإصدار الجديد. إخفاق الإملاء مستثنى بقرار المستخدم.

main وHEAD وorigin/main المحليون عند281089c9020160bdeb9c557e0e2ef2cb4eebf4eb وقت المقابلة؛ لم يحدث fetch. الشفرة الجديدة في worktree، منها ملفات غير متتبعة لازمة للبناء. مقارنة main..HEAD وحدها خالية فلا تثبت إدراج الإصلاح. لم يحدث commit أوmerge أوpush أو نشر. يجب إدراج الملفات الجديدة عند إعداد commit لاحق؛ لا يكفي tracked-only. مفتاح التوقيع الخاص لا يدخل Git.

أصول assets/server وassets/web القديمة مستبعدة من البناء وتبقى حتى استيفاء شرط القبول السابق؛ لا حذف لها الآن. هذا التقرير يقيّد عبارة إتمام الشفرة في التقارير السابقة بما كشفته مقابلة main لاحقًا.
