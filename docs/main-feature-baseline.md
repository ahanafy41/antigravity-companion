## حدود لازمة لحفظ المقصد

الأصل يتيح CORS عاماً فيOPTIONS، ولا يثبت اقتراناً أوCSRF في dispatcher المفحوص؛ [server.py:3657–3708](https://github.com/ahanafy41/antigravity-companion/blob/281089c9020160bdeb9c557e0e2ef2cb4eebf4eb/server/server.py#L3657-L3708). لا يكفي نقل المسارات القديمة لاستعادة الوظائف؛ تبقى حراسةv1 الحالية لازمة، مع حجب الرموز وenv/headers ونصوصCLI الخام.

أصل BootReceiver يستدعي `TermuxBridge.ensureServerRunningAsync` عندBOOT_COMPLETED ونظيريه؛ [BootReceiver.java:17–26](https://github.com/ahanafy41/antigravity-companion/blob/281089c9020160bdeb9c557e0e2ef2cb4eebf4eb/app/src/main/java/com/antigravity/companion/BootReceiver.java#L17-L26). هذا دليل نية الاستعادة بعدboot، لا دليل نجاحها الميداني. لا يوجب استنساخ تشغيل خلفي غير موثق أوتفعيل أذون تلقائياً؛ علامة الاستعادة والتحقق من هوية الخادم والإشعار الأصلية تبقى حدود التنفيذ الحالي.

قرار الاستمرار: تُفصل الوظائف ذات الأفعال الخلفية الحقيقية عنالعناوين وحدها وعننتائج النجاح المفترضة؛ يضع root خطة الوصل بعقودCLI المعلومة ومراحل القبول. لا يتضمن هذا الملف إذناً بتسجيل دخول أوتحديثCLI أوتشغيل مهمة أواتصالMCP خارجي.
