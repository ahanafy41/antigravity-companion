# إصلاح فروق main قبل الدمج

2026-10-05: أذن المستخدم بإصلاح جميع نتائج المقارنة الساكنة مع main على الفرع نفسه، دون اختبارات أو هاتف أو commit/merge/push.

- Python: منع حفظ تعديل مفاتيح إذن CLI في مخزن Companion وحده؛ بيان المالك، وصون القيم المستوردة. اكتشاف plugin enable/disable من المساعدة الحقيقية، وجرد المهارات والأوامر المحلية للقراءة إذا غاب shell subcommand. لا اختراع auth/test أو تغيير أسرار CLI.
- الويب: effort override صريح، وصون أسماء إعداد التنبيه القديمة، واقتراحات المصادر الفعلية وأزرار plugins المعلنة وبيان عدم دعم بقية الأفعال.
- Android: حد Native للطلبات الجارية ونافذة محدودة للمنجزة؛ recovery للإقلاع عبر إشعار وفتح أمامي، بلا بدء خدمة خلفية محظورة. ActionLedger يملك epoch ثابتًا ويخلّي نتائج completed/failed عند بلوغ السعة؛ pending/unknown محفوظة، ومعرفات epoch القديم غير المحفوظة ترفض دون تنفيذ.
- عقد الهاتف: handshake WS journal_ready، وGET /api/v1/device/epoch؛ المعرف المؤثر epoch:nonce، يلتقطه المستهلك قبل طلب جديد فقط. لا توليد epoch جديد أو إعادة فعل قديم بعد إخفاقه. القراءات بلا سجل دائم للصورة؛ لا حسابها فعلًا مؤثرًا.
- بقية الفروق: إحصاء موارد محلي حقيقي وDoctor المتاح، والتصريح بغياب MCP OAuth/test وعقود إدارة المهارات أو تحديث CLI غير المعلنة، مع مسار Termux صريح، دون نجاح زائف.
- أمثلة الانحدار تكتب ولا تنفذ؛ مراجعة clean-code-guard مستقلة، ثم بناء Debug/Release وحزمة خادم موقعة بإصدار جديد. جميع المصادر اللازمة يجب أن تسجل في commit مأذون به لاحقًا؛ لا دمج الآن.
