## إقفال الجدولة والصف

اعتمد المستخدم الخيار الأول صراحة. واجهة المهام توفر رسالة للدور التالي، وموعدًا واحدًا بتوقيت UTC، وskip/run_once إذا فات الموعد والخادم مغلق. API /local-tasks GET/POST، GET /{task_id}، POST /{task_id}/cancel. JSON ذري local-tasks تحت جذر الحفظ الخاص؛ 256 سجلًا و64 عملًا منتظرًا لكل جلسة، دون حذف سجل مجهول أو replay. تحفظ occurrence_id قبل Sessions.start، والاستئناف يقابل run الحقيقي؛ المجهول interrupted. اختيارات النموذج والجهد وcwd باقية. انشغال الجلسة أو ترقية CLI يُبقيان العمل منتظرًا؛ وسياسة الفوات تخص الإنشاء أو العودة بعد الإغلاق. العامل كل ثانية ويقف قبل إغلاق Sessions؛ إخفاق الحفظ يوقف التنفيذ ويظهر في الواجهة. لا تكرار دوري أو خدمة نظام تعمل والخادم مغلق؛ كل موعد مرة واحدة.

فحص API يمنع الإرسال المباشر من تجاوز الرسائل queued المحفوظة، ويشير إلى لوحة المهام لإلحاق رسالة أخرى. لا يخترع run_id قبل التنفيذ. Promise إنشاء الجلسة مشتركة بين الإرسال وحفظ مهمة؛ أثبت Node طلبًا واحدًا عند التزامن. أسماء الأدوات والوسوم وترتيب Tab والبيان غير المقصور على اللون راجعت في الشفرة؛ لا ادعاء قبول هاتف أو قارئ شاشة حي.
