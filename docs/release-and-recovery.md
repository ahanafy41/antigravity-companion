# الإصدار والتثبيت والرجوع

## حراسة الترقية في مصدر 2026-10-07

قبل فتح مثبت APK المفحوص، يثبت التطبيق هوية الخادم بـHMAC ويقابل نسخته وعقد device_protocol=journal_ready_epoch_v1 بنسخة الخادم المضمّنة في APK. اختلاف النسخة أو العقد يمنع المثبت: ثبّت حزمة الخادم الموقعة الموافقة وأعد تشغيل العملية المملوكة صراحة، ثم أعد طلب تثبيت APK. لا يثبّت التطبيق خادمًا تلقائيًا ولا يتجاوز التوقيع. هذا الإصلاح اجتاز الفحص والبناء المحلي، ولم يصدر Release جديد أو يُجرّب OTA على الهاتف؛ [حصيلة التدقيق](branch-audit-fix-report.md).

الإصدار المحلي المعدّ: 1.3.6، رقم APK 12. الإصدار1.3.6/12 مثبت على الهاتف مع خادمه الموافق؛ آخر قبول تفصيلي1.3.2/8. مرجع الأرقام [server/version.json](../server/version.json). البناء Release يحتفظ بهوية التطبيق وشهادته الأصلية، وDebug مستقل عنه.

## التوقيع والحزم

مفتاح Release خارج الملفات المعدة لـGit. الأصل محفوظ محليًا تحت `.tmp/signing/`، ونسخة خط الأساس تحت `.tmp/original-production/`؛ لا مفتاح خاص في حزمة الخادم. بقي المفتاح القديم في تاريخ Git؛ لم تُكتب دعوى بمحو التاريخ ولم يُعد تشكيله.

Gradle يتلقى SIGNING_KEYSTORE وSIGNING_STORE_PASSWORD وSIGNING_KEY_ALIAS وSIGNING_KEY_PASSWORD من البيئة، ويرفض Release الناقص. شهادة server/release-cert.der عامة ومثبتة البصمة. package_release.py يستعمل JDK17 ويطابق شهادة alias، ثم يوقع بيان الملفات بـSHA256withRSA ويخرج ZIP وmanifest.json وmanifest.sig في مجلد إصدار ثابت. لا يستبدل إصدارًا قائمًا ولا ينشر شيئًا.

مصدر Python والويب server/ وحده. Gradle يولد أصوله ويستبعد النسخ القديمة وملفات الفحص. prepare_web_release.py يحسب revision من الأصول قبل البناء؛ --check يرفض القدم. الاعتماد Python في requirements.txt، وOpenSSL لازم للتحقق في Termux. لا تنزيل من mutable main ولا تثبيت خفي للاعتماد.

## التثبيت

install_release.py يقبل --archive و--manifest و--signature، و--root اختيار موضع الحفظ، و--certificate اختيار الشهادة العامة المثبتة. الشهادة افتراضيًا بجوار المثبت المركب أو في server/ داخل المستودع. يثبت مدخلات التحقق في نسخ خاصة محدودة الحجم، ويتحقق من توقيع البيان وبصمات الملفات والجرد ومسارات ZIP قبل التفعيل؛ لا يعيد فتح الملفات الخارجية بعد التحقق.

كل إصدار تحت releases/، والاختيار في current.json مع بصمة البيان، والاختيار السابق في previous.json. تُحفظ إعدادات المستخدم والمحادثات خارج releases/ ولا يعيدها الرجوع إلى زمن قديم. قفل التثبيت المتروك إثر انقطاع يلزم فحصه؛ لا يُحذف تلقائيًا.

--verify-selected يتحقق من توقيع الإصدار المختار وجرده دون قبول ملف زائد أو رابط رمزي. --rollback يتحقق من السابق ثم يبدل المؤشر والمشغل؛ لا يقتل خادمًا قائمًا. أعد تشغيل العملية المملوكة صراحةً لتطبيق اختيار آخر. المشغل يرفض التوقيع أو جردًا مختلفًا قبل تشغيل Python المختار، ويعلن الجاهزية بعد health صحيح.

## الفرق بين الرجوعين

رجوع حزمة Python يبدل الاختيار ويحفظ البيانات. Android لا يقبل APK برقم أدنى كتحديث عادي؛ إن احتيج إلى شفرة Android السابقة بعد رقم 12، وجب بناء حزمة استرداد بالشهادة نفسها وبرقم أعلى، مثل 13. لم تُبنَ حزمة الاسترداد هذه ولم تُجرّب على هاتف.
