# قبول الهاتف: 1.3.2

التاريخ: 2026-10-04. الجهاز: Samsung A55، Android API36، Termux 0.119.0-beta.3. APK رقم 8، وشهادة Release الأصلية مطابقة للمثبت السابق. التجربة مأذون بها؛ أذن المستخدم بمسح بيانات Companion وحده وإغلاق Termux وبإذني RUN_COMMAND وAccessibility والميكروفون. لم تُمسح ملفات Termux أو اعتماد CLI.

## ما ثبت

| الفحص | النتيجة |
|---|---|
| حفظ الأصل | APK القديم محفوظ محليًا؛ أصل الخادم محفوظ في أرشيف داخل تخزين Termux الخاص، لم يُنسخ إلى Download |
| المتطلبات | حدّثت فهارس apt بإذن صريح؛ ثُبت openssl-tool دون ترقية عامة، وثُبت aiohttp==3.13.3 بعد ModuleNotFoundError فعلي |
| التثبيت | حزمة الخادم 1.3.2 وقّعت بالشهادة الأصلية وتحقق منها المثبت على الهاتف؛ settings.json بقي مطابق البصمة قبل التثبيت وبعده |
| البدء البارد | أُغلق Termux ثم فُتح Companion؛ بدأ الخادم من RUN_COMMAND وأعاد health الإصدار 1.3.2 وAPI1 |
| الاقتران الأصلي | ظهر «الخادم متصل ومصادق» و«متصل ومقترن»؛ تحقق HMAC وinstance_id ثم bootstrap مع Cookie وCSRF داخل الهاتف |
| خدمة الوصول | tree completed، snapshot_id/root وأبعاد صحيحة؛ إعادة action_id أعادت الرد نفسه |
| التقاط الشاشة | screenshot completed وJPEG صالح، 15816 بايت؛ لم تُحفظ الصورة أو تُخرج من الهاتف |
| مصادقة WebSocket | اتصال بلا Bearer لم يقبل Upgrade، أعاد HTTP404 من مسار handshake؛ المصدر يتحقق من الرمز وloopback قبل القبول |
| قارئ الشاشة | بقي Jieshuo وخدمات المستخدم الأخرى مفعلة؛ إعادة تمكين Companion أضافته وحده |

## ما لم يثبت

في دورة القبول التالية على 1.3.2 نجحت المحادثة الحية وتذكر العلامة وSSE وإلغاء العملية المملوكة واستئناف conversation_id نفسه، ونجح الضغط والتمرير في قائمة Companion. إخفاق الرجوع ثابت: أغلق Activity والقائمة مفتوحة. أُصلح في مصدر 1.3.3، ولم يُعد فحصه بطلب المستخدم؛ الهاتف غير متصل. نتيجة الإملاء غير محسومة ولا تعد عيبًا أو مانع قبول بقرار المستخدم. OTA وقبول شامل لـTalkBack/Jieshuo وAPI24/API30 واختبار رفض أدوات CLI ما زالت بلا إثبات. لا تحذف الأصول القديمة بهذه الأدلة وحدها.

## سبب الإصلاح ودليله

كان CRLF يفسد shebang، ثم ظهر اختلاف تفسير env bash في RUN_COMMAND الخلفي. البحث قارن الشفرة القديمة بالمصدر الموسوم، وأعاد المعالج نفسه محليًا قبل التجربة التالية. أصلح 1.3.2 المفسر الصريح والنتيجة الاختيارية وملخص الخطأ الآمن؛ [مذكرة التشخيص](termux-phone-diagnosis.md) تفصل المصدر والإثبات. نجح فحص قبول محدد بعد ذلك؛ لا تجارب عشوائية متتابعة لمعالجة العيب.

لا commit أو push أو نشر. السجلات العامة المحدودة وأدلة الأدوات تحت .tmp المستبعدة؛ المفتاح الخاص والرمز لم يخرجا في تقرير أو ملف مشترك.
